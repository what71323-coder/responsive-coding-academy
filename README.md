# CodeCraft Academy

CodeCraft Academy is a fictional coding academy landing page created
using HTML5 and CSS3 as part of a responsive web design assignment.

## Features

- Responsive header and navigation
- Hero section with image and call-to-action buttons
- Three course cards
- About section with benefits
- Sample learner testimonials
- Contact section and footer
- Mobile-first responsive design
- CSS Grid, Flexbox and media queries

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
day-10/
├── index.html
├── README.md
└── css/
    └── style.css
```

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open index.html in a browser.
3. Resize the browser to test mobile, tablet and desktop layouts.

## Responsive Testing

- Mobile: 375px
- Tablet: 768px
- Desktop: 1366px
